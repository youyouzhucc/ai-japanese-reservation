# 支付宝当面付接入说明

审核通过后，按以下步骤配置即可使用真实支付。

---

## 一、Railway 环境变量配置

在 Railway 项目 → **Variables** 中添加：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `PAYMENT_MODE` | `alipay` | 启用支付宝支付 |
| `ALIPAY_APP_ID` | 你的应用 ID | 开放平台应用详情页 |
| `ALIPAY_PRIVATE_KEY` | 应用私钥完整内容 | 含 `-----BEGIN PRIVATE KEY-----` 和 `-----END PRIVATE KEY-----`，可多行 |
| `ALIPAY_PUBLIC_KEY` | 支付宝公钥 | 上传应用公钥后，在开放平台复制 |
| `ALIPAY_NOTIFY_URL` | `https://你的域名/api/alipay/notify` | 如 `https://ai-japanese-reservation-production.up.railway.app/api/alipay/notify` |
| `ALIPAY_SANDBOX` | `false` | 正式环境用 false，沙箱用 true |

---

## 二、支付宝开放平台配置

1. **应用网关**（可选）：填写 `https://你的域名/`
2. **接口加签方式**：已配置应用公钥
3. **当面付**：已签约

---

## 三、私钥格式说明

`ALIPAY_PRIVATE_KEY` 需为完整 PEM 内容，例如：

```
-----BEGIN RSA PRIVATE KEY-----
MIIEpAIBAAKCAQEA...
...多行...
-----END RSA PRIVATE KEY-----
```

在 Railway 中可写为一行，用 `\n` 表示换行，例如：
```
-----BEGIN RSA PRIVATE KEY-----\nMIIEpAIBAAKCAQEA...\n...\n-----END RSA PRIVATE KEY-----
```

或直接粘贴多行（Railway 支持多行变量）。

---

## 四、流程说明

1. 用户填写预约 → 创建预约单（状态：待支付）
2. 用户点击「去支付」→ 调用当面付预创建 → 展示支付二维码
3. 用户扫码支付
4. 支付宝异步通知 `ALIPAY_NOTIFY_URL` → 更新状态为「预约中」→ 触发 AI 电话
5. 用户刷新页面可查看最新状态

---

## 五、测试

1. 沙箱环境：`ALIPAY_SANDBOX=true`，使用沙箱账号测试
2. 正式环境：`ALIPAY_SANDBOX=false`，使用真实支付
