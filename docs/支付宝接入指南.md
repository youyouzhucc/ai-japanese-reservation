# 支付宝当面付接入指南

已开通支付宝开放平台后，按以下步骤完成接入即可实现真实支付能力。

---

## 一、支付宝开放平台配置

### 1. 签约「当面付」

1. 登录 [支付宝开放平台](https://open.alipay.com)
2. 进入 **产品中心** → 找到 **当面付** → 点击 **签约**
3. 按提示完成签约（个人/企业按实际选择）

### 2. 创建应用并添加能力

1. 进入 **控制台** → **网页/移动应用** → **创建应用**
2. 应用创建后，在应用详情中 **添加能力** → 选择 **当面付**
3. 提交审核（通常几分钟内通过）

### 3. 配置密钥（RSA2）

#### 3.1 生成密钥对

1. 下载 [支付宝密钥生成工具](https://opendocs.alipay.com/common/02kipl)
2. 选择 **RSA2(SHA256)**，密钥长度 **2048**
3. 点击 **生成密钥**，得到：
   - **应用私钥**：保存到本地，填写到 `ALIPAY_PRIVATE_KEY`
   - **应用公钥**：需上传到支付宝

#### 3.2 上传应用公钥

1. 进入应用 **开发设置** → **接口加签方式**
2. 选择 **公钥** 模式
3. 粘贴 **应用公钥**（不含头尾、换行），上传
4. 上传成功后，支付宝会显示 **支付宝公钥**，复制保存

#### 3.3 获取 AppID

在应用详情页顶部可见 **AppID**（如 `2021001234567890`）。

## 二、环境变量配置

在项目根目录创建 `.env` 文件（或 Railway 配置 Variables），添加：

```bash
# 支付模式：改为 alipay 启用真实支付
PAYMENT_MODE=alipay

# 支付宝当面付
ALIPAY_APP_ID=你的AppID
ALIPAY_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----
你的应用私钥内容（多行）
-----END RSA PRIVATE KEY-----"

ALIPAY_PUBLIC_KEY="-----BEGIN PUBLIC KEY-----
支付宝公钥内容（从开放平台获取）
-----END PUBLIC KEY-----"

# 异步通知地址（必填！支付宝支付成功后会回调此地址）
# 格式：https://你的域名/api/alipay/notify
ALIPAY_NOTIFY_URL=https://你的域名/api/alipay/notify

# 沙箱环境：true=沙箱测试，false=正式环境
ALIPAY_SANDBOX=false
```

### 私钥格式说明

- 私钥需完整包含 `-----BEGIN RSA PRIVATE KEY-----` 和 `-----END RSA PRIVATE KEY-----`
- 多行时可用 `\n` 或实际换行，环境变量中建议用引号包裹
- 支付宝公钥同理，包含 `-----BEGIN PUBLIC KEY-----` 和 `-----END PUBLIC KEY-----`

### Railway 示例

在 Railway Variables 中：

| 变量名 | 值 |
|--------|-----|
| `PAYMENT_MODE` | `alipay` |
| `ALIPAY_APP_ID` | `2021001234567890` |
| `ALIPAY_PRIVATE_KEY` | 完整私钥（多行可粘贴） |
| `ALIPAY_PUBLIC_KEY` | 完整支付宝公钥 |
| `ALIPAY_NOTIFY_URL` | `https://你的项目名.up.railway.app/api/alipay/notify` |
| `ALIPAY_SANDBOX` | `false`（正式）或 `true`（沙箱） |

## 三、 notify_url 配置

**支付宝支付成功后，会向 `ALIPAY_NOTIFY_URL` 发送 POST 请求。** 必须满足：

1. **公网可访问**：本地开发时需用内网穿透（如 ngrok）暴露 `/api/alipay/notify`
2. **HTTPS**：正式环境必须使用 HTTPS
3. **支付宝白名单**：若使用 IP 白名单，需确保服务器 IP 可被支付宝访问

本地开发示例：

```bash
# 使用 ngrok 暴露本地 8000 端口
ngrok http 8000

# 将生成的 https 地址填入
ALIPAY_NOTIFY_URL=https://xxxx.ngrok.io/api/alipay/notify
```

## 四、沙箱测试（可选）

正式上线前可先用沙箱验证：

1. 开放平台 → **沙箱环境** → 获取沙箱 AppID
2. 沙箱环境需单独配置密钥（沙箱应用有独立的密钥）
3. 设置 `ALIPAY_SANDBOX=true`
4. 使用 [沙箱版支付宝](https://opendocs.alipay.com/common/02kkv7) 扫码测试

---

## 五、支付流程说明

1. 用户提交预约 → 创建待支付订单
2. 用户点击「去支付」→ 后端调用支付宝预创建接口，返回二维码
3. 前端展示二维码，用户扫码支付
4. 支付成功后，支付宝**异步**请求 `ALIPAY_NOTIFY_URL`
5. 后端校验签名并更新订单状态，触发 AI 电话
6. 用户点击「刷新状态」查看预约进度

## 六、常见问题

### 1. 配置后仍提示「未配置支付」

检查 `ALIPAY_APP_ID`、`ALIPAY_PRIVATE_KEY`、`ALIPAY_PUBLIC_KEY` 是否均已填写且格式正确。

### 2. 支付成功但订单未更新

- 确认 `ALIPAY_NOTIFY_URL` 公网可访问
- 查看服务器日志，确认是否收到支付宝回调
- 检查支付宝公钥是否为「支付宝公钥」而非「应用公钥」

### 3. 签名验证失败

- 确认应用私钥与上传到支付宝的应用公钥成对
- 确认支付宝公钥是从开放平台「接口加签方式」中复制的

### 4. 私钥格式错误

确保私钥完整、无多余空格，且包含 BEGIN/END 行。
