# 易付通 V2 接入指南

## 一、环境变量配置

在 Railway Variables 中配置：

| 变量名 | 必填 | 说明 |
|--------|:----:|------|
| `PAYMENT_MODE` | ✅ | `qiufk_v2` |
| `QIUFK_PID` | ✅ | 商户 ID（如 282） |
| `QIUFK_PRIVATE_KEY` | ✅ | 商户 RSA 私钥（用于签名） |
| `QIUFK_PUBLIC_KEY` | ✅ | 平台公钥（用于验签） |
| `QIUFK_API_URL` | ✅ | 易付通 API 地址，如 `https://pay.qiufk.cn` |
| `QIUFK_NOTIFY_URL` | ✅ | 异步通知地址，如 `https://你的域名/api/qiufk/notify` |

## 二、获取密钥

1. 登录易付通商户后台
2. 进入 **个人资料** → **API信息**
3. 点击【生成商户RSA密钥对】
4. 保存 **商户私钥** 到 `QIUFK_PRIVATE_KEY`
5. 复制 **平台公钥** 到 `QIUFK_PUBLIC_KEY`

## 三、API 地址

`QIUFK_API_URL` 需从易付通后台或客服获取，一般为 `https://pay.qiufk.cn` 或类似域名。

## 四、通知地址

`QIUFK_NOTIFY_URL` 必须公网可访问，格式：`https://你的Railway域名/api/qiufk/notify`

## 五、调试

访问 `GET /api/payment-status` 可检查配置是否生效。
