# 易付通 V2 接入指南

## 一、环境变量配置

在 Railway Variables 中配置：

| 变量名 | 必填 | 说明 |
|--------|:----:|------|
| `PAYMENT_MODE` | ✅ | `qiufk_v2` |
| `QIUFK_PID` | ✅ | 商户 ID（如 282） |
| `QIUFK_PRIVATE_KEY` | ✅ | 商户 RSA 私钥（用于签名） |
| `QIUFK_PUBLIC_KEY` | ✅ | 平台公钥（用于验签） |
| `QIUFK_API_URL` | ✅ | 易付通 API 地址，如 `https://pay.qiufk.cn` |
| `QIUFK_NOTIFY_URL` | ✅ | 异步通知地址，如 `https://你的域名/api/qiufk/notify` |

## 二、获取密钥

1. 登录易付通商户后台
2. 进入 **个人资料** → **API信息**
3. 点击【生成商户RSA密钥对】
4. 保存 **商户私钥** 到 `QIUFK_PRIVATE_KEY`
5. 复制 **平台公钥** 到 `QIUFK_PUBLIC_KEY`

## 三、API 地址

`QIUFK_API_URL` 为易付通 API 根地址，文档未明确给出，可尝试：
- `https://www.qiufk.cn`
- `https://pay.qiufk.cn`

建议在商户后台「个人资料 → API 信息」或联系客服确认。

## 四、通知地址

`QIUFK_NOTIFY_URL` 必须公网可访问，格式：`https://你的Railway域名/api/qiufk/notify`

## 五、私钥格式（Railway 变量）

Railway 中配置 `QIUFK_PRIVATE_KEY` 时：

**方式一（推荐）**：直接粘贴完整 PEM，保留换行
```
-----BEGIN RSA PRIVATE KEY-----
MIIEowIBAAKCAQEA...
...多行 base64...
-----END RSA PRIVATE KEY-----
```

**方式二**：单行时用 `\n` 表示换行
```
-----BEGIN RSA PRIVATE KEY-----\nMIIEowIBAAKCAQEA...\n-----END RSA PRIVATE KEY-----
```

若出现 `Could not deserialize key data` 错误，请检查：
1. 是否包含 `-----BEGIN RSA PRIVATE KEY-----` 和 `-----END RSA PRIVATE KEY-----`
2. 多行粘贴时换行是否被保留（可尝试用 `\n` 替代）
3. 是否从易付通商户后台「生成商户RSA密钥对」获取

## 六、调试

访问 `GET /api/payment-status` 可检查配置是否生效。
