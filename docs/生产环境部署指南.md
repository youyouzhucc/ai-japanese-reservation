# 生产环境部署指南 - 真实交易运行

要让系统真实运行（真实支付、真实 AI 电话、真实短信），需要完成以下配置。

---

## 一、部署服务器（必需）

系统需要部署到**公网可访问的服务器**，因为：
- Twilio 需要回调你的 Webhook（必须是 HTTPS）
- 用户需要访问预约页面

**推荐方案：**
- 云服务器：阿里云 / 腾讯云 / AWS / Vercel + Railway
- 需要：公网 IP、HTTPS（可用 Let's Encrypt）

**部署步骤示例（以云服务器为例）：**
```bash
# 1. 安装 Python 3.10+
# 2. 克隆项目
git clone https://github.com/youyouzhucc/ai-japanese-reservation.git
cd ai-japanese-reservation

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置 .env（见下文）
# 5. 使用 gunicorn + nginx 或 systemd 运行
uvicorn main:app --host 0.0.0.0 --port 8000
```

## 二、真实支付

### 1. Stripe（国际支付）

1. 注册：https://dashboard.stripe.com
2. 获取 API Key：Developers → API keys → Secret key
3. 在 `config.py` 中增加 `stripe_secret_key`
4. 在 `services/payment.py` 中实现 Stripe 支付逻辑

```python
# 示例：创建 Stripe 支付
import stripe
stripe.api_key = settings.stripe_secret_key
payment_intent = stripe.PaymentIntent.create(
    amount=amount_cents,
    currency="jpy",  # 或 "cny"
    metadata={"order_no": order_no}
)
```

### 2. 支付宝 / 微信支付（国内）

- 支付宝：https://open.alipay.com
- 微信支付：https://pay.weixin.qq.com
- 需接入对应 SDK，在 `services/payment.py` 中实现

## 三、真实 AI 电话（Twilio）

### 1. 注册 Twilio

1. 注册：https://www.twilio.com

2. 获取凭证：
   - **Account SID**：Console 首页
   - **Auth Token**：Console 首页

3. **购买电话号码**：
   - Phone Numbers → Buy a number
   - 选择支持 Voice 的号码
   - 拨打日本号码：需选择支持国际通话的套餐

4. 配置 `.env`：
```env
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=你的AuthToken
TWILIO_PHONE_NUMBER=+1234567890
```

### 2. 部署 TwiML 端点

Twilio 需要你提供一个 URL，在接通时播放语音。当前代码中 `ai_phone.py` 的 URL 是占位符，需要改为你的实际地址。

**方案 A：预录日语语音**

在 `main.py` 中增加 TwiML 端点：

```python
@app.get("/twiml/{order_no}")
async def twiml_voice(order_no: str, db=Depends(get_db)):
    # 从数据库查询预约信息
    # 生成 TwiML XML，播放日语预约内容
    from twilio.twiml.voice_response import VoiceResponse
    resp = VoiceResponse()
    resp.say("こんにちは、予約代行サービスです。", language="ja-JP")
    # ... 更多 say
    return Response(content=str(resp), media_type="application/xml")
```

**方案 B：TTS 动态生成**

使用 OpenAI TTS 或 Google TTS 将日语文本转成语音，再通过 Twilio 播放。

### 3. 更新 ai_phone.py 中的 URL

将 `https://your-server.com/twiml/{order_no}` 改为你的实际域名，例如：
`https://your-domain.com/twiml/{order_no}`

### 4. 费用说明

- Twilio 电话：按分钟计费，国际通话（如美国 → 日本）约 $0.05–0.15/分钟
- Twilio 短信：约 $0.01/条
- 需在 Twilio 账户预存余额

## 四、真实短信

### 1. Twilio 短信（国际）

配置好 Twilio 后，`services/sms.py` 会自动使用。需确保：
- `TWILIO_PHONE_NUMBER` 支持 SMS
- 目标号码格式正确（如 +86 中国、+81 日本）

### 2. 阿里云短信（国内）

1. 开通：https://dysms.console.aliyun.com
2. 申请签名、模板
3. 获取 AccessKey
4. 配置 `.env`：
```env
ALIYUN_ACCESS_KEY=xxx
ALIYUN_ACCESS_SECRET=xxx
ALIYUN_SMS_SIGN_NAME=你的签名
ALIYUN_SMS_TEMPLATE_CODE=SMS_xxx
```

5. 安装 SDK：`pip install alibabacloud_dysmsapi20170525`

## 六、数据库（生产）

生产环境建议使用 PostgreSQL 或 MySQL：

```env
DATABASE_URL=postgresql+asyncpg://user:pass@host:5432/dbname
# 或
DATABASE_URL=mysql+aiomysql://user:pass@host:3306/dbname
```

需安装：`pip install asyncpg` 或 `pip install aiomysql`

---

## 七、推荐实施顺序

1. **部署**：先把服务部署到公网，确保能访问
2. **配置 Twilio**：完成电话 + 短信（可先测短信）
3. **实现 TwiML**：让 AI 能真实播放日语
4. **接入支付**：Stripe 或支付宝/微信
5. **测试**：用真实号码做端到端测试
