# 真实交易配置清单

当前应用已部署在 Railway，可正常访问。要实现真实交易（真实支付、真实 AI 电话、真实短信），请按以下清单逐项完成。

---

## 一、真实支付

### 方案 A：Stripe（国际用户，推荐）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 注册 Stripe | https://dashboard.stripe.com/register |
| 2 | 完成身份验证 | 按 Stripe 要求提交资料 |
| 3 | 获取 Secret Key | Developers → API keys → Secret key（以 `sk_live_` 开头） |
| 4 | 在 Railway 配置变量 | Variables → 添加 `STRIPE_SECRET_KEY` |
| 5 | 修改 config.py | 增加 `stripe_secret_key: str = ""` |
| 6 | 修改 payment.py | 实现 Stripe PaymentIntent 创建逻辑 |
| 7 | 修改 requirements.txt | 添加 `stripe` |
| 8 | 修改 PAYMENT_MODE | 在 Variables 中设置 `PAYMENT_MODE=stripe` |

**前端需配合：** 使用 Stripe.js 或 Checkout 完成支付，需在前端增加支付跳转/弹窗逻辑。

---

### 方案 B：支付宝（国内用户）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 开通支付宝开放平台 | https://open.alipay.com |
| 2 | 创建应用并签约「当面付」或「手机网站支付」 | 按业务类型选择 |
| 3 | 获取 AppID、私钥、支付宝公钥 | 开发设置中配置 |
| 4 | 在 Railway 配置变量 | `ALIPAY_APP_ID`、`ALIPAY_PRIVATE_KEY`、`ALIPAY_PUBLIC_KEY` |
| 5 | 修改 payment.py | 接入 alipay-sdk-python |
| 6 | 修改 requirements.txt | 添加 `alipay-sdk-python` |

---

### 方案 C：微信支付（国内用户）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 开通微信支付商户号 | https://pay.weixin.qq.com |
| 2 | 获取 API 密钥、证书 | 商户平台 → API 安全 |
| 3 | 在 Railway 配置变量 | `WECHAT_APP_ID`、`WECHAT_MCH_ID`、`WECHAT_API_KEY` |
| 4 | 修改 payment.py | 接入 wechatpayv3 或官方 SDK |

---

## 二、真实 AI 电话（Twilio）

### 2.1 注册与购买

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 注册 Twilio | https://www.twilio.com/try-twilio |
| 2 | 验证邮箱和手机 | 完成账号激活 |
| 3 | 充值账户 | Billing → Add funds（建议先 $20 测试） |
| 4 | 购买电话号码 | Phone Numbers → Buy a number |
| 4.1 | 选择国家 | 美国/加拿大等（支持 Voice） |
| 4.2 | 勾选 Voice 能力 | 必须支持 Voice |
| 4.3 | 确认国际通话 | 拨打日本 +81 需确认套餐支持 |

### 2.2 配置 Railway 变量

在 Railway → Variables 中添加：

| 变量名 | 值 | 获取位置 |
|--------|-----|----------|
| `TWILIO_ACCOUNT_SID` | ACxxxxxxxx | Console 首页 |
| `TWILIO_AUTH_TOKEN` | xxxxxxxx | Console 首页 |
| `TWILIO_PHONE_NUMBER` | +1xxxxxxxxxx | 购买的电话号码 |

### 2.3 部署 TwiML 端点（必需）

Twilio 接通后需要访问一个 URL 获取语音指令。当前代码中 URL 为占位符，需完成：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 在 main.py 中新增 `/twiml/{order_no}` 接口 | 返回 TwiML XML |
| 2 | 在接口中查询预约信息 | 根据 order_no 从数据库读取 |
| 3 | 使用 Twilio 的 TTS 播放日语 | `VoiceResponse().say("こんにちは...", language="ja-JP")` |
| 4 | 修改 ai_phone.py 第 68 行 | 将 URL 改为 `https://ai-japanese-reservation-production.up.railway.app/twiml/{order_no}` |
| 5 | 修改 requirements.txt | 添加 `twilio` |

### 2.4 费用参考

- 美国号码月租：约 $1.15/月
- 拨打日本：约 $0.05–0.15/分钟
- 短信：约 $0.01/条

## 三、真实短信

### 方案 A：Twilio 短信（与电话共用）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 确认 Twilio 号码支持 SMS | 购买时勾选 SMS |
| 2 | 完成上述 Twilio 配置 | 变量已配置即可 |
| 3 | 无需额外代码 | sms.py 已支持，配置变量后自动生效 |

**注意：** 向中国号码发短信需确认 Twilio 是否支持，部分地区可能受限。

---

### 方案 B：阿里云短信（国内推荐）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 开通阿里云短信 | https://dysms.console.aliyun.com |
| 2 | 申请签名 | 如「AI预约」 |
| 3 | 申请模板 | 如「您的预约已成功，餐厅：${restaurant}，时间：${time}」 |
| 4 | 在 Railway 配置变量 | 见下表 |
| 5 | 修改 requirements.txt | 添加 `alibabacloud_dysmsapi20170525` |
| 6 | 修改 sms.py | 适配阿里云模板参数格式 |

**Railway 变量：**

| 变量名 | 说明 |
|--------|------|
| `ALIYUN_ACCESS_KEY` | 访问密钥 ID |
| `ALIYUN_ACCESS_SECRET` | 访问密钥 Secret |
| `ALIYUN_SMS_SIGN_NAME` | 签名名称 |
| `ALIYUN_SMS_TEMPLATE_CODE` | 模板 CODE |

## 四、数据库（可选，生产建议）

当前使用 SQLite，Railway 重启后数据可能丢失。生产环境建议：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 在 Railway 添加 PostgreSQL 或 MySQL | New → Database |
| 2 | 复制连接字符串 | Railway 会自动设置 `DATABASE_URL` |
| 3 | 修改 requirements.txt | 添加 `asyncpg`（PostgreSQL）或 `aiomysql`（MySQL） |
| 4 | 在 Variables 中设置 | `DATABASE_URL=postgresql+asyncpg://...` |
