# 融合认证套餐包 - 下一步配置步骤

你已购买融合认证解决方案套餐包，按以下步骤完成配置即可发送验证码。

---

## 第一步：进入号码认证服务控制台

1. 打开浏览器，访问：**https://dypns.console.aliyun.com/**
2. 使用阿里云账号登录
3. 若首次使用，按提示开通「号码认证服务」

---

## 第二步：查看并记录赠送的签名和模板

1. 在控制台左侧菜单，点击「**短信认证服务**」→「**短信认证参数配置**」
   - 或直接访问：https://dypns.console.aliyun.com/smsCertParamsConfig

2. **签名配置**：
   - 选择「**赠送签名配置**」页签
   - 在列表中任选一个签名，**记下签名名称**（如 `阿里云` 或类似）

3. **模板配置**：
   - 选择「**赠送模板配置**」页签
   - 在列表中任选一个验证码类模板，**记下模板 CODE**（如 `SMS_123456789`）
   - ⚠️ 赠送签名必须搭配赠送模板使用，不能混用自定义签名/模板

---

## 第三步：绑定测试手机号（必做，否则收不到短信）

1. 在控制台左侧，点击「**短信认证服务**」→「**短信认证概览**」
   - 或访问：https://dypns.console.aliyun.com/smsServiceOverview

2. 在页面中找到「**快速测试**」或「**测试手机号**」区域

3. 点击「**绑定测试手机号码**」

4. 在弹窗中输入你的手机号（11 位，如 `15021927073`，**不要加 +86 或 0**）

5. 点击「**确定**」完成绑定

   ⚠️ **重要**：未绑定的手机号无法收到短信！若点击「获取验证码」后显示「验证码已发送」但手机收不到，通常是该号码未在控制台绑定。

---

## 第四步：获取 AccessKey

1. 点击阿里云控制台右上角头像
2. 选择「**AccessKey 管理**」
3. 点击「**创建 AccessKey**」
4. 完成安全验证后，会显示：
   - **AccessKey ID**
   - **AccessKey Secret**（只显示一次，请立即复制保存）

---

## 第五步：在项目中配置 .env

1. 打开终端，进入项目目录：
   ```bash
   cd /Users/cc/95fen/testMontership/ai-japanese-reservation
   ```

2. 若还没有 `.env` 文件，执行：
   ```bash
   cp .env.example .env
   ```

3. 用编辑器打开 `.env`，添加或修改以下配置：

   ```env
   # 阿里云 - 融合认证套餐包（号码认证服务）
   ALIYUN_SMS_MODE=dypnsapi
   ALIYUN_ACCESS_KEY=你的AccessKey ID
   ALIYUN_ACCESS_SECRET=你的AccessKey Secret
   ALIYUN_SMS_SIGN_NAME=第二步记下的签名名称
   ALIYUN_SMS_VERIFY_TEMPLATE_CODE=第二步记下的模板CODE
   ALIYUN_PNVS_INSTANCE_ID=dypns_omniVerifySolution_public_cn-wvc4o8u6w01
   ```

   - `ALIYUN_SMS_MODE=dypnsapi` 表示使用融合认证（号码认证）API
   - `ALIYUN_SMS_SIGN_NAME` 必须与赠送签名列表中的名称**完全一致**
   - `ALIYUN_SMS_VERIFY_TEMPLATE_CODE` 必须与赠送模板的 CODE **完全一致**
   - `ALIYUN_PNVS_INSTANCE_ID` 为你的实例资源 ID（控制台可见，可选，部分场景需要）

4. 保存文件

---

## 第六步：安装依赖并启动

1. 安装依赖（包含号码认证 SDK）：
   ```bash
   pip install -r requirements.txt
   ```

2. 启动服务：
   ```bash
   uvicorn main:app --reload --port 8000
   ```

3. 浏览器访问：http://localhost:8000

---

## 第七步：验证

1. 点击页面任意输入框，弹出登录弹窗
2. 输入你**已绑定的测试手机号**（如 `13800138000`）
3. 点击「获取验证码」
4. 查看手机是否收到短信
5. 输入验证码，点击「登录」

若收到短信且能正常登录，说明配置成功。

---

## 常见问题

**Q：收不到短信？**
- 确认手机号已在「测试手机号」中绑定
- 确认签名名称、模板 CODE 与控制台完全一致（区分大小写、空格）
- 查看终端是否有报错信息

**Q：赠送模板的变量是什么？**
- 赠送模板通常使用 `${code}` 作为验证码占位符，系统会自动替换
- 若模板使用其他变量名，需在代码中对应调整

**Q：套餐包用完了怎么办？**
- 在「短信认证概览」页可查看余量
- 用完后可按量计费，或购买新的套餐包
