# 阿里云短信配置 - 详细步骤

按顺序完成以下步骤，即可实现真实发送登录验证码。

---

## 第一步：注册 / 登录阿里云

1. 打开浏览器，访问：https://www.aliyun.com/
2. 点击右上角「登录」
3. 使用支付宝或手机号注册 / 登录

---

## 第二步：开通短信服务

1. 登录后，在页面顶部搜索框输入「**短信服务**」
2. 在搜索结果中点击「短信服务」产品
3. 进入产品页后，点击「**立即开通**」或「**免费开通**」
4. 选择「**国内消息**」按量付费（无月租，用多少付多少）
5. 阅读并同意服务协议，完成开通

---

## 第三步：申请短信签名

1. 在短信服务控制台左侧菜单，点击「**国内消息**」
2. 再点击「**签名管理**」
3. 点击右上角「**添加签名**」按钮
4. 按以下内容填写：

   | 字段 | 填写内容 | 说明 |
   |------|----------|------|
   | 签名名称 | `AI预约` | 会显示在短信开头，如【AI预约】 |
   | 签名来源 | 选择「**网站**」 | 若没有网站可选「APP」 |
   | 签名说明 | `AI日语预约系统登录验证码` | 简要说明用途 |

5. 点击「**提交**」
6. 等待审核（通常 10 分钟～2 小时），状态变为「**审核通过**」后继续

---

## 第四步：申请验证码模板

1. 在左侧菜单点击「**模板管理**」
2. 点击右上角「**添加模板**」
3. 按以下内容填写：

   | 字段 | 填写内容 |
   |------|----------|
   | 模板类型 | 选择「**验证码**」 |
   | 模板名称 | `登录验证码` |
   | 模板内容 | `您的验证码是${code}，5分钟内有效，请勿泄露。` |

   ⚠️ **重要**：必须包含 `${code}`，系统会自动替换为 6 位数字验证码。

4. 点击「**提交**」
5. 审核通过后，在模板列表中找到该模板，**记下「模板 CODE」**（格式如 `SMS_123456789`）

---

## 第五步：添加测试手机号（未正式上线必做）

1. 在左侧菜单点击「**数据统计**」或「**概览**」
2. 找到「**测试手机号**」或「**短信发送设置**」相关入口
3. 添加你的手机号（11 位，如 `13800138000`）
4. 未添加的号码在测试阶段无法收到短信

> 若找不到测试手机号入口，可在「**国内消息**」→「**发送记录**」页面附近查找，或搜索「测试」关键词。

---

## 第六步：获取 AccessKey

1. 点击页面右上角头像
2. 选择「**AccessKey 管理**」（若提示开通 RAM，按提示开通）
3. 点击「**创建 AccessKey**」
4. 按提示完成安全验证（手机验证码等）
5. 创建成功后，会显示：
   - **AccessKey ID**：形如 `LTAI5txxxxxxxxxx`
   - **AccessKey Secret**：形如 `xxxxxxxxxxxxxxxx`
6. **立即复制保存** AccessKey Secret，关闭后无法再次查看

---

## 第七步：在项目中配置 .env

1. 打开终端，进入项目目录：
   ```bash
   cd /Users/cc/95fen/testMontership/ai-japanese-reservation
   ```

2. 复制配置文件：
   ```bash
   cp .env.example .env
   ```

3. 用编辑器打开 `.env` 文件

4. 找到阿里云相关配置，去掉前面的 `#`，并填入你的真实值：
   ```env
   ALIYUN_ACCESS_KEY=LTAI5txxxxxxxxxx
   ALIYUN_ACCESS_SECRET=xxxxxxxxxxxxxxxx
   ALIYUN_SMS_SIGN_NAME=AI预约
   ALIYUN_SMS_VERIFY_TEMPLATE_CODE=SMS_123456789
   ```

   - `ALIYUN_ACCESS_KEY`：第六步的 AccessKey ID
   - `ALIYUN_ACCESS_SECRET`：第六步的 AccessKey Secret
   - `ALIYUN_SMS_SIGN_NAME`：与第三步的签名名称**完全一致**
   - `ALIYUN_SMS_VERIFY_TEMPLATE_CODE`：第四步记下的模板 CODE

5. 保存文件

---

## 第八步：安装依赖并启动服务

1. 安装 Python 依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 启动服务：
   ```bash
   uvicorn main:app --reload --host 0.0.0.0 --port 8000
   ```

3. 浏览器访问：http://localhost:8000

---

## 第九步：验证是否成功

1. 在页面中点击任意预约输入框（如「搜索餐厅」）
2. 弹出登录弹窗后，输入你的**测试手机号**（如 `13800138000` 或 `+86 138 0013 8000`）
3. 点击「获取验证码」
4. 查看手机是否收到短信，内容类似：`【AI预约】您的验证码是123456，5分钟内有效，请勿泄露。`
5. 在弹窗中输入收到的验证码，点击「登录」
6. 若能正常登录，说明配置成功

## 常见问题

**Q：收不到短信？**
- 确认手机号已添加到「测试手机号」
- 确认签名、模板均为「审核通过」
- 查看控制台终端是否有报错信息

**Q：提示「签名不存在」或「模板不存在」？**
- 检查 `.env` 中签名名称、模板 CODE 是否与阿里云控制台完全一致（区分大小写、空格）

**Q：提示「isv.BUSINESS_LIMIT_CONTROL」？**
- 短信发送频率受限，同一手机号 1 分钟内只能发 1 条，请稍后再试
